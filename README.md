## Repository Structure

```
EUVDBD/
├── index.html                         # Library homepage (stable)
├── games.json                         # Auto-generated game catalog
├── games/
│   └── dot-battle/
│       ├── index.html                 # Dot Battle game
│       └── game.json                  # Metadata (title, description, emoji)
├── .github/
│   └── workflows/
│       └── update-game-index.yml      # Auto-generates games.json on push
└── README.md
```

## Adding a New Game

1. Create a folder under `games/` using a lowercase slug (letters, numbers, hyphens only):
   ```
   games/my-awesome-game/
   ```

2. Add an `index.html` file with your game.

3. Optionally add a `game.json` for custom metadata:
   ```json
   {
     "title": "My Awesome Game",
     "description": "A short description shown on the homepage.",
     "emoji": "\ud83c\udfae"
   }
   ```
   Without `game.json`, the folder name will be used as the title with a generic icon.

4. Push to `main`. The GitHub Actions workflow will automatically scan `games/*/index.html`, regenerate `games.json`, and commit it. The homepage will display the new game card on the next load.

## How It Works

- **Homepage** (`index.html`): Fetches `./games.json` and renders game cards dynamically. No manual editing needed.
- **Catalog** (`games.json`): Auto-generated by GitHub Actions on every push that touches `games/**`.
- **GitHub Pages**: Serves static files from the `main` branch root.

## Notes

- Only folders containing `index.html` are listed on the homepage.
- Folder slugs must match `[a-z0-9][a-z0-9-]*` (lowercase letters, numbers, hyphens).
- Game URLs are stable and version-independent (e.g. `/games/dot-battle/`).
